VOICIGAME (made with AI)
========================

Play The Choicer Voicer with friends who don't own the game. They join with a room code
on their phone or in any browser at https://voicigame.duckdns.org


INSTALL ON WINDOWS
------------------
Easiest: Voicitool (https://github.com/Jan1653/Voicitool)
  Settings > Voicigame > Install mod.

By hand:
  1. Extract this whole ZIP into the game folder, next to the game's exe.
  2. Double-click "Install Voicigame.bat".
     Steam folder under Program Files: right-click, "Run as administrator".
  3. Start the game: Play > Voicigame.


INSTALL ON LINUX (should work, not tested yet)
----------------------------------------------
  1. Extract this whole ZIP into the game folder, next to the game file.
  2. Open a terminal in that folder and run:   sh install-linux.sh
  3. Start the game: Play > Voicigame.

The game files stay unchanged. The installer only adds one line to override.cfg.


UPDATES
-------
The mod updates itself: on start it gets the newest version from the server,
it runs from the next start. With Voicitool, Voicitool does the updates.


REMOVE
------
Windows: double-click "Uninstall Voicigame.bat".   Linux: sh uninstall-linux.sh
Then delete the "voicigame" folder.


PLAY
----
Create lobby: shows a room code, a QR code and a link. Friends open it and pick a name.
Continue = gameshow, Dubbing = dub mode. Join lobby = play along from your own copy of the game.
Language: bottom of the Voicigame menu (default: system language).
